# AthleticOS

[Open and install AthleticOS](https://yagohboo.github.io/athleticos/)

Version 3.3.0. A personal strength and athletic performance app. This repository contains its compiled static release. Hosting uses GitHub Pages; no paid services or app account are needed.

On iPhone, open the app in Safari, tap Share, then Add to Home Screen. Enable Open as Web App if offered. Launch once online and wait for Offline ready.

For an existing installation, keep its icon and this same address. Save current entries, export a backup from Profile, then open online and accept Update app. Do not uninstall or clear site data to update.

Version 3 adds protected updates, recoverable drafts, password-encrypted backups, local recovery copies, Recently deleted, gym planning and logging tools, multi-attempt athletic tests, calendar export, daily check-ins and ingredient/portion/meal-prep tools. All operate locally without paid APIs.

Version 3.1 makes those tools easier to use: everyday shortcuts, searchable tools, compact mobile menus, one-set workout logging and expandable settings and reviews. It also fixes draft restoration, duplicate-save prevention, nutrition date switching and workout timing. Existing features and saved records are retained. Profile → App updates shows the installed version and checks for updates.

Workout records, photos and settings stay in your browser or installed app. They do not sync across devices. Local copies share the same device storage; save periodic exported backups outside the app.

Version 3.2 adds personal setup for goals, experience, equipment and schedule. Each phone creates its own starting plan. Start workout opens the session directly, guided logging shows the current set first, and rest names what comes next. New profiles start without inherited body measurements or nutrition targets. Existing plans, workouts and advanced tools remain available.

Version 3.3 gives Today a training journal layout with your workout, start or resume action and week in view. During a session, see your current exercise and set, open the exercise list with Plan, and follow the next set from the rest timer. The new light and dark themes work offline.
