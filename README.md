# AthleticOS

[Open and install AthleticOS](https://yagohboo.github.io/athleticos/)

A personal strength and athletic performance app. This repository contains its compiled static release. Hosting uses GitHub Pages; no paid services or app account are needed.

On iPhone, open the app in Safari, tap Share, then Add to Home Screen. Enable Open as Web App if offered. Launch once online and wait for Offline ready.

Workout records, photos and settings stay in your browser or installed app. They do not sync across devices. Export backups from Profile regularly.
