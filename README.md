# AthleticOS

[Open and install AthleticOS](https://yagohboo.github.io/athleticos/)

Version 3.0.0. A personal strength and athletic performance app. This repository contains its compiled static release. Hosting uses GitHub Pages; no paid services or app account are needed.

On iPhone, open the app in Safari, tap Share, then Add to Home Screen. Enable Open as Web App if offered. Launch once online and wait for Offline ready.

For an existing installation, keep its icon and this same address. Save current entries, export a backup from Profile, then open online and accept Update app. Do not uninstall or clear site data to update.

Version 3 adds protected updates, recoverable drafts, password-encrypted backups, local recovery copies, Recently deleted, gym planning and logging tools, multi-attempt athletic tests, calendar export, daily check-ins and ingredient/portion/meal-prep tools. All operate locally without paid APIs.

Workout records, photos and settings stay in your browser or installed app. They do not sync across devices. Local copies share the same device storage; save periodic exported backups outside the app.
